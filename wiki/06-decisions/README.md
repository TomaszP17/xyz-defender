# Rejestr decyzji

- [0001 — ustalenia bazowe](0001-baseline.md): zaakceptowane na podstawie poleceń właściciela.

Kolejne decyzje: numer, tytuł, data, status, kontekst, decyzja, uzasadnienie i konsekwencje. Statusy: proponowana, zaakceptowana, zastąpiona.

Rekomendacje technologiczne pozostają w ../03-architecture/technology.md do zatwierdzenia. Nie tworzymy pozornie zaakceptowanych ADR dla otwartych kwestii.
